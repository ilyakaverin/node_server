# Сертификаты НУЦ Минцифры

Сайты госорганов, в том числе roskazna.gov.ru, используют TLS-сертификаты
Национального удостоверяющего центра Минцифры. Его корневого сертификата нет в
стандартном хранилище Node.js, поэтому парсер (`utils/scraper.js`) доверяет
стандартным корневым сертификатам и, кроме них, всем файлам `*.pem` и `*.crt`
из этого каталога. Промежуточные сертификаты лежат здесь на случай, если сервер
не передаёт их сам: Node.js не скачивает недостающие звенья цепочки.

| Файл | Сертификат | Действует до (UTC) | SHA-256 |
| ---- | ---------- | ------------------ | ------- |
| `russian_trusted_root_ca.pem` | Russian Trusted Root CA (корневой) | 27.02.2032 21:04:15 | `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31` |
| `russian_trusted_sub_ca.pem` | Russian Trusted Sub CA (промежуточный, выпуск 2022 г.) | 06.03.2027 11:25:19 | `BB:BD:E2:10:3E:79:0B:99:9E:C6:2B:D0:3C:F6:25:A5:A2:E7:C3:16:E1:0A:FE:6A:49:0E:ED:EA:D8:B3:FD:9B` |

## Откуда взяты

Официальный источник — <https://www.gosuslugi.ru/crt>. Из среды, в которой
добавлялись файлы, он был недоступен, поэтому сертификаты взяты из пакетов
нескольких независимых издателей в трёх реестрах, с проверкой контрольных сумм
архивов по данным реестров:

- npm: `gigachat` 0.0.3, `infobot-sber-stt` 1.1.4, `@adamianps/n8n-nodes-gigachat` 2.2.0;
- PyPI: `salute-speech` 2.0.0;
- RubyGems: `gigachat-ruby` 0.1.2.

Сертификаты во всех пакетах побайтно совпадают. Отпечатки совпадают с
опубликованными независимо: отчёты SSL Labs для сайтов с этой цепочкой,
документация Сбера (developers.sber.ru), баг Mozilla 1758773. Подпись
промежуточного сертификата проверена корневым (`openssl verify -x509_strict`).
Файлы перекодированы из DER в PEM, сами сертификаты не изменялись.

Отпечатки стоит один раз сверить с официальным сайтом:

```sh
openssl x509 -in certs/russian_trusted_root_ca.pem -noout -fingerprint -sha256
```

## Обновление

1. Скачайте актуальные сертификаты в формате PEM с <https://www.gosuslugi.ru/crt>
   и положите их в этот каталог (один сертификат на файл).
2. Добавьте отпечаток каждого файла в `PINNED` в `test/certs.test.js` — тест не
   пропустит несверенный файл.
3. Просроченные промежуточные сертификаты можно удалить. Тест упадёт, если
   просрочены корневой сертификат или все промежуточные.
